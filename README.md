# PMC Spawn Toggle

PMC Spawn Toggle adds a simple F12 menu option that allows you to disable AI-controlled USEC and BEAR spawns before entering a raid.
When enabled, the mod removes both existing PMC waves and the custom PMC waves that SPT normally generates for each raid. Other AI remains unaffected, including regular and sniper Scavs, bosses and their followers, Rogues, Raiders, Cultists, and other special enemies. Your own PMC character is also unaffected.
The setting can only be changed outside a raid. Once a raid begins, the option is locked until you return to the main menu, preventing unsafe changes during active gameplay. The selected value is synchronized directly with the SPT server and checked again during raid generation to ensure the correct mode is applied.
This mod is useful for players who want Scav-focused raids, quieter exploration, testing environments, survival challenges without AI PMCs, or greater control over SPT’s enemy population without manually editing server configuration files.
Features:
Enables or disables AI PMC spawning through the F12 menu.
Removes both USEC and BEAR AI.
Preserves Scavs, bosses, followers, Rogues, Raiders and special AI.
Prevents SPT’s per-raid PMC generator from adding PMCs back.
Locks the option while a raid is active.
Restores normal PMC spawning when disabled.
